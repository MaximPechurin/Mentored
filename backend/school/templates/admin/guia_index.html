🎓 Гайд по учебной платформе (Школа)

Как это устроено в целом

В системе есть две разные сущности «курс»:

  • Курс-товар (раздел MENTORED → Курсы) — то, что продаётся в магазине: цена, обложка, описание для витрины.
  • Учебный курс (раздел Школа · Работа с курсами → Учебные курсы) — сам контент: модули, уроки, задания, прогресс студентов.

Связывает их «Доступ к курсу через товар»: покупка товара открывает доступ к привязанному учебному курсу.

Как добавить новый курс (пошагово)
  1. Учебный курс: Школа · Работа с курсами → Учебные курсы → Добавить. Впишите название и описание. Тут же внизу (инлайны) добавьте Разделы и назначьте Преподавателя.
  2. Уроки: откройте созданный Раздел курса → внизу инлайн Уроки (название, порядок, ссылка на видео, текст, длительность).
  3. Материалы и задания: откройте Урок → внизу инлайны Материалы урока (файлы) и Домашние задания.
  4. Чтобы курс продавался: создайте Курс-товар (MENTORED → Курсы) с ценой, затем свяжите: Школа → Доступы к курсам через товары → Добавить (тип товара = course, ID товара, учебный курс).
Как пользователь покупает и что видит после покупки
  1. Пользователь регистрируется (автоматически получает роль student).
  2. Покупает курс-товар (оплата Mercado Pago). После оплаты автоматически создаётся «Доступ к курсу» (Enrollment) — вручную ничего делать не нужно.
  3. В личном кабинете («Ir a la Escuela» → кабинет студента) он видит купленные курсы, заходит внутрь: разделы → уроки (видео, текст, материалы), отмечает пройденное, сдаёт домашние задания.

Раздел «Школа» пока виден только пользователям с галочкой is_dev (тест-режим). Снять ограничение — когда будете открывать школу всем.

Домашние задания: как принимаются
  1. Преподаватель создаёт Домашнее задание на уроке (описание + максимальный балл).
  2. Студент в кабинете пишет ответ (текст и/или файл) и отправляет — статус «На проверке».
  3. Преподаватель проверяет: Школа · Студенты и доступы → Ответы на домашние задания → открыть сдачу → поставить статус, оценку, комментарий → сохранить.
Что где хранится (блоки админки)
  • 🎓 Работа с курсами — учебные курсы, разделы, уроки, материалы, задания, преподаватели, связки товар↔курс.
  • 👤 Студенты и доступы — доступы к курсам (кто что купил), прогресс по урокам, ответы на ДЗ, профили преподавателей.
  • 💬 Общение — темы и сообщения форума, личные сообщения.
  • MENTORED — пользователи, роли, товары (курсы/книги/консультации/подписки), заказы, блог.

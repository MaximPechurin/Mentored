🛍️ Гайд по сайту (магазин, заказы, блог)

Как это устроено в целом

Сайт продаёт 4 типа товаров: Книга, Курс, Консультация, Абонемент (раздел MENTORED → Сайт · Витрина). У всех общие поля - цена, старая цена (для скидки), картинка, «Активен» (показывать в магазине) и «На главной» (выделить как рекомендуемый), плюс свои характеристики (у книги - формат/страницы, у курса - длительность/уроки и т.п.).

Покупка идёт так: пользователь добавляет товар в Корзину (Cart/CartItem) → оформляет Заказ (Order) → платит через Mercado Pago → создаётся/обновляется Платёж (Payment) → при успехе статус заказа становится paid.

Если оплаченный товар - это Курс, привязанный к учебному курсу через «Доступ к курсу через товар» - доступ к Школе откроется автоматически, это та точка, где сайт и Школа соединяются (подробнее в гайде по Школе ниже).

Как добавить новый товар (пошагово)
  1. Выберите тип: MENTORED → Книги / Курсы / Консультации / Абонементы → Добавить.
  2. Заполните название (слаг для ссылки заполнится сам), описание, цену, картинку.
  3. Заполните характеристики товара (для книги - формат/страницы/файл, для курса - длительность/уроки/уровень и т.д.).
  4. Поставьте галочку «Активен» - без неё товар не появится в магазине. «На главной» - по желанию, для рекламы товара.

Это Курс-товар (карточка в магазине с ценой) - не путать с Учебным курсом (сам контент уроков) в разделе Школы. Чтобы товар реально открывал доступ к учебному курсу, их нужно связать - см. гайд по Школе, шаг «Чтобы курс продавался».

Заказы и оплата
  1. MENTORED → Сайт · Заказы и оплата → Заказы - список всех заказов, статус, сумма, состав (инлайн товаров внутри заказа).
  2. Статусы заказа: pending (создан, не оплачен) → paid (оплачен) → processing/completed (в работе/выполнен), либо cancelled/refunded.
  3. Платежи - отдельная модель (данные от Mercado Pago: транзакция, статус, сумма) - обычно смотрят их, только если нужно разобраться со спорной оплатой; сам заказ и его статус меняются автоматически.
Блог, вопросы-ответы, отзывы
  • Блог - Категории блога и Посты блога (заголовок, картинка, текст, категория).
  • FAQ - вопросы-ответы для страницы с частыми вопросами.
  • Отзывы - отзывы клиентов (имя, фото, текст) для витрины.
Пользователи, роли и обращения
  • Пользователи - все зарегистрированные аккаунты; галочка is_dev открывает им раздел «Школа» (пока она не открыта всем).
  • Роли - student/teacher, назначаются пользователю (M2M), от них зависит, что человек видит в Школе.
  • Обращения - сообщения с формы обратной связи на сайте.

🎓 Гайд по учебной платформе (Школа)

Как это устроено в целом

В системе есть две разные сущности «курс»:

  • Курс-товар (раздел 🛍️ Сайт · Витрина → Курсы) — то, что продаётся в магазине: цена, обложка, описание для витрины.
  • Учебный курс (раздел Школа · Работа с курсами → Учебные курсы) — сам контент: модули, уроки, задания, прогресс студентов.

Связывает их «Доступ к курсу через товар»: покупка товара открывает доступ к привязанному учебному курсу.

Как добавить новый курс (пошагово)
  1. Учебный курс: Школа · Работа с курсами → Учебные курсы → Добавить. Впишите название и описание. Тут же внизу (инлайны) добавьте Разделы и назначьте Преподавателя.
  2. Уроки: откройте созданный Раздел курса → внизу инлайн Уроки (название, порядок, ссылка на видео, текст, длительность).
  3. Материалы и задания: откройте Урок → внизу инлайны Материалы урока (файлы) и Домашние задания.
  4. Чтобы курс продавался: создайте Курс-товар (🛍️ Сайт · Витрина → Курсы) с ценой, затем свяжите: либо прямо на странице учебного курса внизу инлайн «Доступы к курсам через товары», либо Школа → Доступы к курсам через товары → Добавить - в обоих местах товар выбирается из выпадающего списка (по названию и цене), учебный курс - тоже из списка.
Как пользователь покупает и что видит после покупки
  1. Пользователь регистрируется (автоматически получает роль student).
  2. Покупает курс-товар (оплата Mercado Pago). После оплаты автоматически создаётся «Доступ к курсу» (Enrollment) — вручную ничего делать не нужно.
  3. В личном кабинете («Ir a la Escuela» → кабинет студента) он видит купленные курсы, заходит внутрь: разделы → уроки (видео, текст, материалы), отмечает пройденное, сдаёт домашние задания.

Раздел «Школа» пока виден только пользователям с галочкой is_dev (тест-режим). Снять ограничение — когда будете открывать школу всем.

Домашние задания: как принимаются
  1. Преподаватель создаёт Домашнее задание на уроке (описание + максимальный балл).
  2. Студент в кабинете пишет ответ (текст и/или файл) и отправляет — статус «На проверке».
  3. Преподаватель проверяет: Школа · Студенты и доступы → Ответы на домашние задания → открыть сдачу → поставить статус, оценку, комментарий → сохранить.
Что где хранится (блоки админки)
  • 🎓 Работа с курсами — учебные курсы, разделы, уроки, материалы, задания, преподаватели, связки товар↔курс.
  • 👤 Студенты и доступы — доступы к курсам (кто что купил), прогресс по урокам, ответы на ДЗ и комментарии к ним, профили преподавателей.
  • 💬 Общение — темы и сообщения форума, личные сообщения.

  • 🧾 Заказы и оплата — корзины, заказы, платежи.
  • 📝 Контент — блог, FAQ, отзывы.
  • 👤 Пользователи и роли, ✉️ Обращения — аккаунты, роли, форма обратной связи.
